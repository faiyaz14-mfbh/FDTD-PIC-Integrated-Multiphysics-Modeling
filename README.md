# FDTD-PIC-Integrated-Multiphysics-Modeling

MATLAB code for simulating how terahertz/mmWave fields interact with drifting electrons in the two-dimensional electron gas (2DEG) of a GaN/AlGaN HEMT. A 2D finite-difference time-domain (FDTD) electromagnetic solver is coupled to a 1D particle-in-cell (PIC / Monte Carlo) model of the channel electrons. The device sits inside a parallel-plate waveguide and has a metal grating gate.

---

## Repository contents

| File | Purpose |
|---|---|
| `MC.m` | Standalone particle model of the 2DEG with no EM coupling. Injects electrons and lets them drift until the channel reaches a steady state, then saves that state as the starting point for the coupled run. |
| `FDTD_WG_PIC.m` | Main coupled simulation. 2D TEz FDTD (Ex, Ey, Hz) with PML and PEC walls, a 29-strip grating gate excited by a 300 GHz source, and a PIC model of the 2DEG that both responds to and radiates into the field. |
| `ParticleView.m` | Post-processing plots run on the workspace of `FDTD_WG_PIC.m`: particle velocities vs position, electron density, current density, and a field map around the channel. |


## Requirements

- MATLAB (any recent release)
- Statistics and Machine Learning Toolbox (for `normrnd`, used for particle injection)

No other toolboxes or external libraries are needed.

---

## Workflow

```
MC.m  ──►  steady-state particle file (.mat)  ──►  FDTD_WG_PIC.m  ──►  ParticleView.m
```

1. **Generate the initial particle state**
   Run `MC.m`. It saves a workspace snapshot `OUtput_<step>.mat` every 1000 steps. The last snapshot holds the steady-state particles (`part_x`, `part_v`, `np`) and the injection/2DEG parameters (`np_i`, `np_insert`, `tt_insert`, `v_drift`, `n_sh_m2`, `part_max`).

2. **Point the FDTD script to that file**
   `FDTD_WG_PIC.m` loads its initial state in the "Particle initialization" section:
   ```matlab
   load('MC_Current_1p0e5_dx_10nm_L_5um_delV_200.mat');
   ```
   Rename your snapshot to this name, or edit the line to point to your file.
   Make sure the channel length, cell size (`dx_2DEG`), and time step `dt` in `MC.m` match the FDTD run (see [Known issues](#known-issues)).

3. **Run the coupled simulation**
   Run `FDTD_WG_PIC.m`. Set `mesh_only = 1` first if you only want to build and check the geometry plots without starting the time loop.

4. **Plot the results**
   With the FDTD workspace still loaded (or after loading one of its `Output_*.mat` files), run `ParticleView.m`.
